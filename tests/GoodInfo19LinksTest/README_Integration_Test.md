# GoodInfo 19 Links 整合測試說明

## 📋 測試內容

整合測試方法：`IntegrationTest_All19Links_Should_Success`

一次性執行所有 19 個 GoodInfo Links 下載測試，自動處理：
- ✅ 每個 link 之間自動間隔 10 秒（防反爬蟲）
- ✅ 自動記錄每個測試的執行時間
- ✅ 自動統計成功/失敗數量
- ✅ 自動輸出詳細測試報告

## 🚀 執行方式

### 方法 1：執行整合測試（推薦）
```powershell
cd d:\vibeCoding\sst\tests\GoodInfo19LinksTest

```



## ⚠️ 注意事項

1. **反爬蟲機制**
   - 每個測試之間必須間隔 10 秒
   - 整合測試已自動處理
   - 不要在短時間內重複執行

2. **測試環境**
   - Chrome 瀏覽器必須已安裝
   - ChromeDriver 版本需匹配
   - 網路連線必須穩定

3. **可能的失敗原因**
   - 網路連線問題
   - GoodInfo 網站維護
   - 瀏覽器版本不匹配
   - 反爬蟲機制觸發

4. **失敗處理**
   - 等待 5-10 分鐘後重試
   - 檢查網路連線
   - 清除 `D:\ChromeUserData` 資料夾
   - 更新 ChromeDriver

## 🔧 疑難排解

### 問題：找不到 ChromeDriver
```powershell
# 檢查 ChromeDriver 是否在 PATH 中
Get-Command chromedriver
```

### 問題：測試超時
- 增加網路等待時間
- 檢查 GoodInfo 網站是否正常
- 減少並行測試數量

### 問題：廣告攔截失敗
- 程式已自動處理 `ats-interstitial-container`
- 如仍失敗，可能需要更新廣告處理邏輯
