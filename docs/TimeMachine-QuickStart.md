打开新的 PowerShell 窗口：


### 第三步: 访问时光机

浏览器打开: http://localhost:5005/time-machine

## 📋 使用说明

1. **选择分析日期**: 例如 2025-12-01
2. **调整筛选条件** (可选):
   - 最小成熟度: 60 (推荐)
   - 量能倍数: 10-50
   - 冷却天数: 8-30
3. **点击"分析"按钮**
4. **查看结果**:
   - 统计摘要: 成功率、平均报酬等
   - 推荐列表: 每支股票的详细信息
   - 价格走势: 点击"查看"按钮展开图表

## 🔧 故障排除

### 问题 1: "分析失败"

**可能原因**: 连接字符串未配置

**解决方案**:
1. 检查 `src/SST.StockImport.API/appsettings.json`
2. 确认 `ConnectionStrings:DefaultConnection` 配置正确
3. 格式示例: `"Server=localhost;Database=sst;User=root;Password=;"`

### 问题 2: "没有找到符合条件的候选"

**可能原因**: 筛选条件过严

**解决方案**:
1. 降低最小成熟度 (例如 40)
2. 扩大量能范围 (例如 5-100)
3. 调整冷却天数 (例如 5-60)

### 问题 3: API 无法连接

**检查清单**:
- [ ] API 项目已启动 (端口 5008)
- [ ] 数据库连接正常 (MySQL 8.0.31)
- [ ] `appsettings.json` 中 BaseUrl 配置正确
