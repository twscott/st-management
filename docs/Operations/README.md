# Docs/Operations - 日常操作手册

这个目录包含 SST 系统的日常运维操作指南。

## 📁 应该放在这里的文档

- **数据库操作**: 切换、备份、恢复、导入、导出
- **常见错误处理**: 错误目录与解决方案
- **导入流程**: 三阶段导入详细步骤
- **启动与部署**: 系统启动、配置、监控
- **故障排查**: 常见问题诊断流程

## 📄 当前文档（计划）

- `Database_Procedures.md` - 数据库操作完整指南（整合自 DATABASE-SWITCHER-GUIDE.md）
- `Import_Workflow.md` - 三阶段导入流程（来自 IMPORTANT-IMPORT-FLOW.md）
- `Common_Errors.md` - 常见错误目录（从 Session Reports 提取）

## 🎯 使用场景

当工程师遇到以下情况时查阅：
- 需要切换数据库环境
- 导入数据出错
- 遇到生产环境问题
- 需要执行日常维护任务
