# 时光机回测优化 - 使用说明

## 📝 目标

寻找**21天内获利30%**，且**准确率≥80%**的最佳推荐条件。

分析三种信号源：
1. **量能爆发** (alertlist)
2. **大阳线** (tradedata)  
3. **长下影线** (t_longshadowcover)

## 🚀 快速开始

### 方法1：Python分析（推荐⭐）

```powershell
# 1. 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 2. 运行分析
python backtest-optimization.py

# 3. 查看结果
# 会生成 CSV 文件，包含所有配置的测试结果
```

**优点**：
- ✅ 最快速（5-10分钟）
- ✅ 准确度高
- ✅ 自动生成CSV报告
- ✅ 实时显示高准确率配置

**输出示例**：

访问 http://localhost:5089/time-machine

- 追踪天数：21

### 步骤3：验证和调整

## ⚠️ 注意事项

### 1. 过拟合风险

如果某个配置样本数太少（<10），可能是偶然。建议：
- 优先选择样本数≥20的配置
- 在其他时间段验证

### 2. 市场环境变化

历史表现不代表未来。建议：
- 定期重新分析（每月）
- 结合当前市场环境判断

### 3. 数据质量

确保数据库包含完整的历史数据：
- stock60days 表有足够天数
- KD指标已计算完成

## 🐛 常见问题

### Q1: 分析跑了很久没反应？

A: 正常，取决于数据量。Python版本5-10分钟，PowerShell+API可能20分钟。

### Q2: 没有找到≥80%准确率的配置？

A: 可能需要：
- 放宽参数范围
- 降低目标获利率（从30%降到25%）
- 延长追踪天数（从21天到30天）
- 增加历史分析期间（从90天到180天）

### Q3: 样本数太少怎么办？

A: 扩大搜索范围或延长分析期间。
