- 量能爆发 (0)
- 大阳线≥6% (1)

### 步骤 2：点击智能推荐

点击 "分析" 按钮，查看历史推荐结果

## 📊 配置逻辑说明

### 参数选择依据

#### 1. **KD 范围** 
- **热点/长下影线**：20-70（低位进场）
  - 理由：这两种信号通常是底部反弹，需要在低KD时进场
- **大阳线**：30-80（确认趋势）
  - 理由：大阳线是强势信号，可以在稍高KD值进场

#### 2. **冷却天数**
- **热点/大阳线**：10-30天
  - 理由：充分冷却，避免追高
- **长下影线**：10-25天
  - 理由：底部反弹信号，较快进场

#### 3. **成熟度阈值**
- **热点/长下影线**：≥60分
- **大阳线**：≥65分  
  - 理由：大阳线本身已经是强信号，需要更高成熟度确保质量

#### 4. **成交量倍数**
- **热点**：10-40倍
  - 理由：过高的成交量倍数(>40倍)可能意味着过热
- **大阳线/长下影线**：不限制
  - 理由：这两种信号的判断主要依赖价格形态，而非成交量
