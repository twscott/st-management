根據您提供的 UI 截圖，以下是各按鈕應該調用的 API 端點：

## 🟢 單一市場匯入（測試用）

| UI 按鈕 | API 端點 | 說明 | 建議使用場景 |
|---------|---------|------|-------------|
| 🏠 上市股票 (TWSE) | `POST /api/import/two-phase?market=TSE` | 僅匯入上市股票 | 測試、補充單一市場 |
| 🏢 上櫃股票 (OTC) | `POST /api/import/two-phase?market=OTC` | 僅匯入上櫃股票 | 測試、補充單一市場 |
| 🌱 興櫃股票 | `POST /api/import/two-phase?market=EMERGING` | 僅匯入興櫃股票 | 測試、補充單一市場 |

**⚠️ 注意**：這些端點**不會執行 Phase 2 統計計算**，僅用於測試或補充特定市場資料。

## 🎯 使用流程建議

### 日常收盤後（每天 13:35）

1. **點擊「整合匯入資料」按鈕**
   ```
   呼叫：POST /api/import/three-phase?includeGoodInfo=true
   ```

2. **等待執行完成**（約 30-40 分鐘）
   - Phase 1: 三個交易所匯入
   - Phase 2: 統計計算
   - Phase 3: GoodInfo 匯入

3. **檢查結果**
   - 若有失敗：點擊「重試失敗股票」
   - 查看詳情：點擊「查看任務狀態」

### 特殊情況：僅更新特定市場

1. **點擊對應的市場按鈕**（如「上市股票」）
   ```
   呼叫：POST /api/import/two-phase?market=TSE
   ```

2. **⚠️ 注意**：此操作**不會執行統計計算**
   - 僅用於補充特定市場的遺漏資料
   - 如需統計計算，仍需執行「整合匯入資料」

## 🚫 常見錯誤

### ❌ 錯誤做法 1：分別執行各市場
```
點擊「上市股票」→ 等待完成
點擊「上櫃股票」→ 等待完成
點擊「興櫃股票」→ 等待完成
點擊「GoodInfo 資料」→ ❌ 資料會不完整！
```

**問題**：跳過了 Phase 2 統計計算，GoodInfo 資料會缺少必要的衍生指標。

### ❌ 錯誤做法 2：單獨執行 GoodInfo
```
直接點擊「GoodInfo 資料」→ ❌ 缺少基礎資料！
```

**問題**：沒有執行 Phase 1 和 Phase 2，GoodInfo 無法正確匯入。

### ✅ 正確做法：使用整合匯入
```
點擊「整合匯入資料」→ 系統自動執行完整流程 ✅
```

## 📝 開發建議

建議在 UI 上加入以下提示：

1. **「整合匯入資料」按鈕**
   - 使用醒目顏色（如金色或亮綠色）
   - 加上「推薦」或「日常使用」標籤
   - 顯示預估執行時間（30-40 分鐘）

2. **單一市場按鈕**
   - 加上「測試用」或「進階」標籤
   - 提示「不包含統計計算」

3. **GoodInfo 按鈕**
   - 如果要保留，應該改為「查看 GoodInfo 設定」
   - 或直接移除，統一使用「整合匯入資料」

4. **執行中狀態**
   - 顯示當前執行的階段（Phase 1/2/3）
   - 顯示進度百分比
   - 顯示預估剩餘時間
