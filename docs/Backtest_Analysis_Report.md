## 🔍 重要洞察

### ⚠️ 警示發現

1. **成功率極低**
   - 前 30 天內達成 30% 獲利的成功率 < 1%
   - 這與您的痛苦經驗完全一致：「發熱當下進場 → 被痛宰」

2. **最佳窗口在 30 天之後**
   - 30+ 天的成功率最高：
     - 20% 目標：1.57%
     - 30% 目標：0.93%
     - 50% 目標：0.35%
   - 這印證了您說的「放了兩三個月才大漲」

3. **早期進場風險極高**
   - Day 1-7: 30% 成功率僅 0.16-0.43%
   - 平均報酬接近 0 或負值

## 📊 建議的成熟度評分調整

基於回測結果，建議調整評分權重：

```csharp
public decimal CalculateMaturityScore(HotspotCandidate candidate)
{
    decimal score = 0;
    
    // 1. 時間因素 (0-30分) - 調整為更長時間
    var daysSince = (DateTime.Now - candidate.HotspotDate).Days;
    if (daysSince >= 15 && daysSince <= 25)
        score += 30;  // 15-25 天為最佳窗口
    else if (daysSince > 25 && daysSince <= 40)
        score += 25;  // 次佳
    else if (daysSince > 40)
        score += 15;  // 長期持有
    else if (daysSince >= 8 && daysSince < 15)
        score += 10;  // 早期仍有風險
    
    // 2. 更嚴格的量能條件 (0-30分)
    if (candidate.PeakVolumeRatio >= 20)  // 至少 20 倍
        score += 15;
    
    if (candidate.VolumeScore > 50)  // 高量能評分
        score += 15;
    
    // 3. 資金流向 (0-20分)
    if (candidate.PositiveAmtCount > candidate.NegativeAmtCount)
        score += 20;  // 資金淨流入
    
    // 4. 價格回檔 (0-20分)
    var retracement = (candidate.PeakPrice - candidate.CurrentPrice) / candidate.PeakPrice;
    if (retracement >= 0.10m && retracement <= 0.20m)
        score += 20;  // 回檔 10-20%
    else if (retracement >= 0.05m && retracement < 0.10m)
        score += 10;  // 輕微回檔
    
    return Math.Min(score, 100);
}
```
