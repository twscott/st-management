# Docs/Archive - 历史记录归档

这个目录存放历史文档、Session Reports、已完成的任务等。

## 📁 子目录结构

### `Sessions/`
存放所有 Session Reports（按日期命名的会话报告）

**命名格式**: `yyyyMMdd_HHmm_SessionReport.md`

**保留原因**: 
- 提供历史上下文
- 问题排查参考
- 技术决策追溯

**清理策略**:
- > 6 个月的报告可考虑压缩存档
- 关键里程碑报告永久保留

### `Milestones/`（未来可创建）
存放项目里程碑、完成确认文档

### `Scripts/`（未来可创建）
存放一次性使用的脚本（如 fix-*.ps1, check-feb24-*.py）

## 🎯 使用场景

当工程师需要以下信息时查阅：
- 查找历史问题的解决方案
- 了解某个功能的开发历程
- 追溯技术决策的原因
- 参考过去的错误修复方法

## ⚠️ 注意事项

- 归档的文档**不应该被频繁引用**
- 如果某个归档文档经常被查阅，考虑将其移到 Operations/ 或 Reference/
- 保持归档目录整洁，定期清理过时内容
