2. **統計邏輯澄清**:
   - 確認成功/失敗計算方式：按下載**類別數量**統計（如：券資比、法人買賣超）
   - 不是按 CSV 檔案內部資料筆數統計
   
3. **E2E 測試建立**:
   - 建立完整的端到端測試環境驗證修正效果
   - 使用 Playwright 測試真實瀏覽器交互
