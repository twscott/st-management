## 🎯 設計決策與架構考量

### 設計原則
1. **模組化設計**: 四個獨立組件，各司其職
2. **漸進式策略**: 冷卻時間逐步增加，避免過度限制
3. **智能驗證**: 不只檢查 HTTP 狀態，驗證實際數據內容
4. **非侵入式**: 最小化對現有代碼的影響

### 技術選型說明
- **偵測策略**: 基於多重信號檢測 (404, 驗證碼, 網絡錯誤, 數據異常)
- **冷卻機制**: 採用指數退避策略，但上限控制在8小時
- **數據驗證**: DOM 元素檢查 + 內容大小驗證雙重保障
- **監控策略**: 滾動視窗統計，提供實時反饋
