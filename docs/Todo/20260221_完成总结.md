## 🎓 关键学习点

1. **原生 SQL vs LINQ**: 复杂评分逻辑用原生 SQL 性能更好，但牺牲了单元测试可行性
2. **子查询优化**: HAVING 子句需要 GROUP BY 或聚合函数，改用子查询 + WHERE 效果更好
3. **Blazor 动态渲染**: 使用计算属性（`SuccessfulCandidates`）实现高效的条件筛选
4. **综合评分算法**: 多维度加权平均（成熟度 40% + 涨幅 40% + 速度 20%）比单一指标更准确
5. **用户价值优先**: "一天只要很准地给我挑一两只" → 实现精选推荐 Top 10 + 筛选开关
