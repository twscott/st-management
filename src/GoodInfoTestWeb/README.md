# GoodInfo 測試網頁應用

這是一個獨立的網頁應用，用於測試 GoodInfo 19 個資料下載連結。

## 功能

1. **單一測試**：點擊每個 link 旁的「測試」按鈕，單獨測試該連結
2. **整合測試**：點擊「執行整合測試」按鈕，依序測試所有 19 個連結（每個間隔 10 秒）
3. **即時結果**：顯示測試狀態（測試中/成功/失敗）和詳細訊息
4. **測試摘要**：整合測試完成後顯示成功/失敗統計

## 使用方式

### 1. 啟動應用

```powershell
cd d:\vibeCoding\sst\src\GoodInfoTestWeb
dotnet run
```

### 2. 開啟瀏覽器

訪問 `https://localhost:5001` 或 `http://localhost:5000`

### 3. 測試

- **單一測試**：點擊任意 link 的「測試」按鈕
- **整合測試**：點擊頂部的「執行整合測試」按鈕

## 測試結果說明

- **綠色**：測試成功，檔案下載完成
- **紅色**：測試失敗，顯示錯誤訊息
- **黃色**：測試進行中

## 注意事項

1. 測試會自動清理 Chrome 進程
2. CSV 檔案會下載到 `Downloads` 資料夾
3. 整合測試約需 10-15 分鐘完成（19 個測試 + 間隔時間）
4. 建議在非高峰時段執行整合測試
